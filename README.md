## Personal Portfolio Website

A fully responsive, multi-page portfolio website showcasing my work, skills, and background as an aspiring full-stack developer. The project includes a homepage with work examples, an about page, and a dedicated work/projects section. All pages follow modern accessibility, responsiveness, and browser-compatibility standards.

## 🚀 Key Features

Homepage

Short introduction about me

Direct links to selected work examples

Featured project section

Overview of who I am

My relevant skills and strengths

Tools, technologies, and programming languages I work with

Work / Projects Page

Collection of selected work examples

Each project includes a title, description, and link

Clean grid layout that adapts from desktop → tablet → mobile

Contact Section

Contact details integrated in the footer on every page
or

Separate contact page

## 🛠️ Technical Requirements Implemented

✔ At least 3 interconnected HTML pages
✔ One external CSS file containing all styles
✔ Use of CSS variables / or SCSS for styling
✔ No external CSS libraries (all code written manually)
✔ Valid HTML (passes W3C Markup Validation Service)
✔ Accessible color contrast (AA level compliance)
✔ Responsive design from 1920px → 320px
✔ Cross-browser compatibility:
Chrome, Firefox, Safari, Edge, Opera, and IE11
✔ Full input compatibility: keyboard, mouse, and touch
✔ Hosted on GitHub in a public repository
✔ Optional: Deployed via GitHub Pages or another server

## 🧰 Tech Stack

HTML5

CSS3 (using CSS variables or SCSS)

Responsive Web Design

Git & GitHub

Optional: Autoprefixer / Preprocessor workflow (if used locally)
