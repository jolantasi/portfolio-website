Personal Portfolio Website

A responsive, accessible portfolio built from scratch to present my work, skills, and growth as a web developer.

Overview

This project is my personal portfolio website, created to showcase my web development journey, technical skills, and completed projects in a clean and professional way. It serves as both an online résumé and a living project that evolves as I grow as a developer.

Purpose & Context

This was a self-initiated project developed during my web development bootcamp. The goal was to apply everything I had learned in HTML and CSS by building a complete, real-world website from scratch rather than following tutorials or templates.

Objective

  • Create a professional online presence
  • Present projects in a clear and structured way
  • Practice semantic HTML and modern CSS layout techniques
  • Ensure responsiveness and accessibility across devices

Duration

The project timeframe was set from July 22 to September 15, 2024. I successfully completed the portfolio within this period. Since then, I continuously update the site whenever I finish new projects, add new skills, or refine the design and usability.

Credits

Role: Sole designer and developer
Collaboration: None — individual project

Tools, Skills & Methodologies

HTML5, CSS3, Responsive Design, CSS Grid, Flexbox, Semantic Markup, Accessibility Best Practices, Performance Optimization

Process & Approach

1. Planning & Structure

I began by defining the purpose of the website and outlining its structure. This step was important to ensure clarity for visitors and scalability for future updates.

I decided on multiple pages to separate concerns clearly (projects, skills, contact), which improved navigation and maintainability.

2. Semantic HTML Foundation

I built the site using semantic HTML elements such as <header>, <main>, <section>, and <footer>. This improved accessibility, SEO, and overall document structure.

This decision also made the code easier to read and maintain as the project grew.

3. Layout & Responsive Design

I implemented CSS Grid and Flexbox to create flexible, responsive layouts. Grid was used for project listings and overall page structure, while Flexbox helped align smaller components.

One challenge was maintaining consistent spacing across screen sizes. I solved this by using relative units, media queries, and reusable CSS components.

4. Reusable CSS & Styling

I created reusable CSS classes for typography, spacing, and components to keep the design consistent and reduce repetition.

The minimal design was a deliberate choice to keep the focus on content and projects, while still appearing modern and professional.

5. Accessibility & Refinement

Accessibility was considered throughout the project by using proper heading hierarchy, readable color contrasts, and descriptive link text.

I continuously tested the site on different devices and screen sizes and refined spacing, alignment, and readability.

Final Result & Reflection

The final result is a fully responsive, accessible, and professional portfolio website that clearly communicates my skills and projects. The original objective of creating a strong personal developer presence was successfully achieved.

Challenges & Learnings

The most challenging part was balancing clean design with flexibility for future growth. This project taught me how important planning, semantic structure, and reusable CSS are for long-term maintainability.

Next Steps

I plan to continue improving the portfolio by refining animations, enhancing performance, and expanding it as I build more complex projects. The site remains an evolving reflection of my development journey.
